## 2. Ringkasan Dasar Teori
*Data Manipulation Language* (DML) adalah sekumpulan perintah SQL yang digunakan untuk memanipulasi isi data di dalam objek tabel yang telah dirancang melalui DDL. Perintah utamanya meliputi `INSERT` untuk menambah baris data baru, `UPDATE` untuk memperbarui atribut data yang sudah ada, serta `DELETE` untuk menghapus data berdasarkan kriteria tertentu. Integritas data harus tetap dijaga agar relasi antar-tabel tidak rusak selama proses manipulasi berlangsung.

## 3. Hasil Langkah Percobaan
* **Penyisipan Data (INSERT):** Berhasil memasukkan data awal uji coba ke dalam tabel `petugas` dan `anggota` pada skema basis data `kopma_24430056`.
* **Pembaruan & Penghapusan Data (UPDATE & DELETE):** Berhasil mengubah nomor kontak serta memperbarui status keaktifan data menggunakan klausa kondisi `WHERE`.

## 4. Jawaban Titik Analisis
* **Apa perbedaan mendasar antara perintah `DELETE` dan `TRUNCATE` dalam DML/DDL?**
  * *Jawaban:* Perintah `DELETE` menghapus data baris per baris dan dapat difilter menggunakan klausul `WHERE` (serta bisa dibatalkan jika dalam transaksi), sedangkan `TRUNCATE` membersihkan seluruh isi tabel secara cepat tanpa memfilter kondisi dan mereset ulang penghitung *Auto Increment*-nya.
